# Research Working Area

This directory will hold part-specific semantic extractions, source crawls, claim ledgers, quantitative notebooks, experimental protocols and validation reports. It must not contain the canonical manuscripts.

The accepted research packages are:

- `Part_1/`, supporting the MSME lifecycle and collection-cascade manuscript.
- `Part_2a/`, supporting the temporal evidence, explicit-feature and residual-AI manuscript.

Each package contains:

- source extraction by section;
- Kenyan MSME evidence table;
- collectability and lifecycle definitions;
- ecosystem responsibility map;
- a part-specific claim ledger;
- detailed narrative and diagram outline;
- reference-order ledger;
- a validation report after the first complete draft.
