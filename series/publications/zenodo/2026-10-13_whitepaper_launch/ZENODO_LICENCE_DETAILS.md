# Zenodo licence details

Select the standard licence **Creative Commons Attribution-NonCommercial-ShareAlike 4.0 International** using Zenodo’s licence search. Its identifier is **CC-BY-NC-SA-4.0**.

If you use the custom-licence form shown in the screenshot, enter:

**Title**

Creative Commons Attribution-NonCommercial-ShareAlike 4.0 International

**Description**

The original text and diagrams may be shared and adapted for non-commercial purposes with appropriate attribution to Nevil Maloba, a link to the licence and an indication of changes. Adaptations must be distributed under the same licence.

**Link**

https://creativecommons.org/licenses/by-nc-sa/4.0/

The record’s main Description field takes the separate `ZENODO_DESCRIPTION.md` text. The licence Description field takes the short licence wording above.

Sources: [Zenodo licence instructions](https://help.zenodo.org/docs/deposit/describe-records/licenses/) and [Creative Commons licence deed](https://creativecommons.org/licenses/by-nc-sa/4.0/).
